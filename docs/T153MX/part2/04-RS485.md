# RS485 通信测试

本章节说明 OmniGate-T153 两路 RS485 的连接和双向通信方法。

## 准备工作

- 两根短接线
- 当前板卡原理图或串口映射说明
- 已进入开发板串口终端

## 硬件连接

断电后连接：

```text
RS485-1 A  -------- RS485-2 A
RS485-1 B  -------- RS485-2 B
GND         -------- GND
```

两路 RS485 位于开发板左侧绿色端子。A/B 的准确端子顺序以 PCB 丝印为准。

## 确认设备节点

在 **开发板 Linux Shell**执行：

```bash
dmesg | grep -Ei 'tty|uart|485'
ls -l /dev/tty*
```

当前资料尚未确认“RS485-1、RS485-2”与 `/dev/tty*` 的准确对应关系，也未确认 DE/RE 方向控制方式。请根据对应批次原理图填写：

## 设置波特率

确认节点后，在 **开发板 Linux Shell**执行：

```bash
stty -F <RS485_1_DEV> 115200 cs8 -cstopb -parenb raw -echo
stty -F <RS485_2_DEV> 115200 cs8 -cstopb -parenb raw -echo
```

## 测试双向通信

在第一个终端监听 RS485-1：

```bash
cat <RS485_1_DEV>
```

在第二个终端从 RS485-2 发送：

```bash
echo 100ask > <RS485_2_DEV>
```

第一个终端能看到 `100ask`，表示一个方向通信正常。按 `Ctrl+C` 停止监听，交换两个设备节点再测试一次。

如果只能接收不能发送，重点检查 RS485 收发使能方向，而不是只修改波特率。
