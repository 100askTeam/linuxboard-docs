# RS485 通信测试

本章节使用 OmniGate-T153 的一路 RS485 和一个 USB 转 RS485 模块完成收发闭环。当前 Buildroot 配置已将 Modbus RTU 默认端口设置为 `/dev/ttyAS5`；另一路 RS485 的设备节点仍需结合板卡原理图实板确认。

## 准备工作

- USB 转 RS485 模块和三根连接线
- 一台 Ubuntu 主机
- 当前板卡原理图或接口丝印说明
- 已进入开发板串口终端

## 硬件连接

断电后连接开发板 RS485-1 和 USB 转 RS485 模块：

```text
OmniGate-T153 RS485-1 A  -------- USB-RS485 A
OmniGate-T153 RS485-1 B  -------- USB-RS485 B
OmniGate-T153 GND        -------- USB-RS485 GND
```

RS485 接口位于开发板左侧绿色端子。A/B 的准确端子顺序以 PCB 丝印和当前批次原理图为准；没有共地时通信可能不稳定。

## 确认设备节点

在 **开发板 Linux Shell**执行：

```bash
ls -l /dev/ttyAS5
dmesg | grep -Ei 'ttyAS5|uart5'
```

当前 OmniGate Buildroot 的 ThingsBoard Modbus 配置默认使用：

```text
RS485-1：/dev/ttyAS5
默认 Modbus 参数：9600 8N1
```

如果 `/dev/ttyAS5` 不存在，先确认当前镜像和设备树，不要用其他 `/dev/ttyAS*` 节点盲试。另一路接口在映射完成实板验证前不写死设备节点。

## 设置波特率

在 **开发板 Linux Shell**执行：

```bash
stty -F /dev/ttyAS5 115200 cs8 -cstopb -parenb raw -echo
```

在 **Ubuntu 主机**确认 USB 转 RS485 节点，并设置相同参数：

```bash
ls -l /dev/ttyUSB*
stty -F <USB_RS485_DEV> 115200 cs8 -cstopb -parenb raw -echo
```

## 测试开发板发送

在 **Ubuntu 主机终端 1**监听：

```bash
cat <USB_RS485_DEV>
```

在 **开发板 Linux Shell**发送：

```bash
echo 'OmniGate RS485 TX' > /dev/ttyAS5
```

Ubuntu 主机看到 `OmniGate RS485 TX`，表示开发板发送正常。按 `Ctrl+C` 停止监听。

## 测试开发板接收

在 **开发板 Linux Shell**监听：

```bash
cat /dev/ttyAS5
```

在 **Ubuntu 主机终端 2**发送：

```bash
echo 'USB RS485 TX' > <USB_RS485_DEV>
```

开发板看到 `USB RS485 TX`，表示开发板接收正常。

## 测试通过标准

- 已根据当前批次接口丝印正确连接 A、B 和 GND。
- 两端使用相同的波特率、数据位、停止位和校验设置。
- 开发板发送的文本能被 Ubuntu 主机接收，主机发送的文本也能被开发板接收。

:::caution 当前文档限制

当前 SDK 配置可以确认 `/dev/ttyAS5` 是默认 Modbus RTU 端口，但 RS485-1 与端子的对应关系及第二路设备节点仍需实板确认。量产验收前应根据原理图和测试结果补齐映射表。

:::
